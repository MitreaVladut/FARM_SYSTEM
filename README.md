# 🚜 Farm Management System

A comprehensive, full-stack Farm Management System designed to optimize agricultural operations, from crop production planning and spatial parcel mapping to inventory logistics and automated reporting.

## 🌟 Project Overview
This application provides a centralized platform for farm administrators and staff to manage land, crops, and logistics through an intuitive interface. It bridges the gap between field-level manual operations and digital farm management.

## 🚀 Key Features
* **Advanced Geometry Engine:** Supports both standard rectangular parcels and custom-drawn polygons for precise land management.
* **Collision Detection:** Intelligent algorithms prevent overlapping parcels during creation and expansion to ensure spatial integrity.
* **Seasonal Validation:** Automated status transitions ensure crops are only planned/planted during their appropriate growth seasons.
* **Production Analytics:** Real-time generation of production-vs-demand reports with visual data mapping.
* **Data Integrity:** Strict import/export validation for system backups and data migration.

## 🛠️ Tech Stack
* **Frontend & Backend:** [Reflex](https://reflex.dev/) (Python-based framework)
* **Database:** MongoDB
* **Visualization:** Plotly & Recharts
* **Security:** `bcrypt` for secure authentication and RBAC
* **CI/CD:** GitHub Actions (Automated Linting & Security Checks)

## 📋 Role-Based Access
* **Admin:** Full access to staff management, system backups, crop registration, and financial reporting.
* **Staff:** Order fulfillment, daily scheduling, and inventory management.
* **Customer:** Order placement, history tracking, and pre-delivery cancellation.
